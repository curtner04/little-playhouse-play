# Little Playhouse changelog

## 1.1.0 - 2026-11-11

- **The companion is Heidi**, named after Caroline's dog. Every spoken line that used to say "Buddy" now says "Heidi", the pet game is now **Heidi Care**, and Dress Up starts with "Let's dress up Heidi!" A phone that saved the old default name switches to Heidi on its own.
- **Online:** the app now lives at https://curtner04.github.io/little-playhouse-play/, so it can be added to the home screen and played offline.
- Search engines are asked not to list the app.
- Grown-ups: the name field is now "Companion's name". It changes the name tag in Dress Up; the voice always says "Heidi".

## 1.0.0 - 2026-11-11

First release.

- **16 learning games:** Memory Match, Clean Up Time, Duck Goes Potty, ABC Fun, Counting Fun, Animal Sounds, Color Splash, Shape Sorter, Bubble Pop, Buddy Care, Shadow Match, Music Maker, Coloring Book, Trace It, Hide and Seek and Feelings.
- **Buddy, the companion:** a French bulldog by default. In Dress Up she can switch Buddy to a puppy, kitty, bunny, teddy bear, panda or unicorn, and change coat, spots, eyes, hats, glasses, collars and outfits. Buddy cheers in every game.
- **Voice:** every instruction is spoken in the same friendly voice as Little Buttons (rendered offline, no internet needed). Sound effects and music are made by the app itself.
- **Sticker Book:** finishing a game earns a sticker.
- **Two levels:** Little (about 2-3) and Big kid (about 4-5).
- **Grown-ups area** (hold the gear for 2.5 seconds): names, level, voice/sound/music volume, play-time break, games shown on the home screen, install help, version and changelog, Restart, export / import configuration (as a file, or copied and pasted as text), undo last import, reset.
- **Installable phone app** that works offline after the first visit and updates itself in the background; Restart loads a downloaded update.
