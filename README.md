# Little Playhouse

Bright, voice-guided learning games for toddlers, as a phone web app.

**Play:** https://curtner04.github.io/little-playhouse-play/

On iPhone, open it in Safari, tap Share, then **Add to Home Screen**. On Android, open it in Chrome, tap the menu, then **Install app**. After the first visit it works offline.

This repository holds only the published build (version 1.3.0). Version history: [CHANGELOG.md](CHANGELOG.md). Third-party notices: [THIRD-PARTY.txt](THIRD-PARTY.txt).
